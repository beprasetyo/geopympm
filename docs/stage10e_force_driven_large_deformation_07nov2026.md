# Stage 10E — Force-Driven Finite-Stretch Validation (7 November 2026)

## Scope and baseline

This validation-only addition is based on the **GeoPyMPM Stage 10D** full source. It does **not modify** the production `src/geopympm/` solver, constitutive models, or interpolation kernels. The new benchmark is in `validation/stage10e/nonlinear_wave.py`, with automated tests in `tests/test_stage10e_nonlinear_wave.py`. Only the existing Stage-7 corotational (Jaumann) elasticity and Stage-8/9 exponential kinematics/advection are used.

**Claim supported:** An exact nonlinear **plane-strain axial** wave benchmark with a peak initial longitudinal stretch of 1.55 (55% extension) is force-driven, with no prescribed x velocities or x external forces during evolution. This permits an independent reference for Cauchy stress, longitudinal stretch, and velocity, before characteristic intersection.

**Not supported:** A general finite-strain hyperelasticity verification, large-shear or bending force-driven validation, granular collapse, plasticity, contact, conservation of total energy for arbitrary 2D Jaumann motions, or a landslide runout validation.

## 1. Derivation of independent reference

The existing material follows the plane-strain, objective Jaumann Cauchy stress rate law

\[
\overset{\triangle}{\boldsymbol\sigma} = \lambda\operatorname{tr}(\mathbf D)\mathbf I + 2\mu\mathbf D,
\]

where the Jaumann correction vanishes for *pure axial* motion with no spin, \(x=x(X,t), y=Y\). Let \(J=\partial x/\partial X>0\), \(v=\partial x/\partial t\), and \(M=\lambda+2\mu\). Then

\[
\sigma_{xx}=M\ln J,\quad \sigma_{yy}=\sigma_{zz}=\lambda\ln J,\quad
\rho=\rho_0/J.
\]

The Lagrangian equations for the 1D reduction are

\[
\frac{\partial J}{\partial t}=\frac{\partial v}{\partial X},\qquad
\frac{\partial v}{\partial t}=\frac{M}{\rho_0}\frac{\partial(\ln J)}{\partial X}.
\]

Define \(c_0=\sqrt{M/\rho_0}\) and \(c(J)=c_0/\sqrt{J}\). A **right-traveling nonlinear simple wave** has invariant

\[
v+2c_0\sqrt J=2c_0,\qquad v=2c_0(1-\sqrt J),
\]

so \(J_t+c(J)J_X=0\). With initial Gaussian stretch

\[
J_0(X)=1+0.55\exp[-(X-4)^2/(2\times0.7^2)],
\]

the exact, pre-shock solution follows the implicit characteristic relation

\[
X=\xi+c(J_0(\xi))t,\qquad J(X,t)=J_0(\xi),\quad
\sigma_{xx}(X,t)=M\ln J(X,t).
\]

The benchmark independently solves for \(\xi\) by bisection on bracket \([X-c_0t,\ X-c_0t/\sqrt{1.55}]\). The minimum derivative of characteristic position with respect to its starting coordinate at \(t=0.45\) s is approximately **0.9207**, strictly positive; thus no characteristic shock occurs in this interval. The characteristic-based reference is not derived from MPM kernels.

The finite-deformation reference is not the linear-elastic d'Alembert solution used in Stages 10A–10C. It is exact for this particular 1D reduction of the current Jaumann hypoelastic constitutive rate.

## 2. Initial configuration and correct state reference

The initial physical particle positions are generated by integrating \(dx/dX=J_0(X)\) using an error function. Particle masses are \(m_p=\rho_0\Delta X\Delta Y\), physical volumes are \(V_p^0=J_0(X_p)\Delta X\Delta Y\), initial velocities are the right-going simple-wave velocities, and initial stresses satisfy \(\sigma^0_{xx}=M\ln J_0\), \(\sigma^0_{yy}=\sigma^0_{zz}=\lambda\ln J_0\).

**Critical implementation detail:** the GeoPyMPM `deformation_gradient` and `volume0` refer to **MPM initialization**, not the undeformed analytical reference. Therefore `ParticleSet.deformation_gradient` is initialized to \(\mathbf I\); we do **not** inject \(\operatorname{diag}(J_0,1)\) into that field. Instead, total analytical stretch is compared to \(J_0(X_p)F^{MPM}_{xx,p}\). The initial GIMP/CPDI domain is assigned its *physical stretched side length* \(J_0\Delta X\) in the x direction; domain_size0 is the physical size at MPM initialization. This avoids violating the Stage-8 identity `volume = volume0 * det(F_MPM)`.

The background grid is fixed and extends from 0 to 12 m; there are no prescribed horizontal nodal velocities, horizontal tractions, or gravity. Vertical grid velocities are constrained to zero to enforce the 1D plane-strain reduction within 2D solver. The initial nonuniform stress pulse produces nonzero internal forces and axial grid accelerations. The simulation evolves via the existing solver's force/P2G/G2P feedback.

## 3. Results of Stage 10E run

For grid spacing 0.25 m, 2 PPC per direction, and t=0.45 s:

| Interpolation | Final relative σxx L2 error | Final relative total axial stretch L2 error | Max relative energy drift |
|---|---:|---:|---:|
| Standard MPM | 26.462% | 5.727% | 1.4425% |
| uGIMP | 1.546% | 0.303% | 0.00710% |
| cpGIMP | 1.345% | 0.246% | 0.01124% |
| CPDI1 | 1.504% | 0.276% | 0.01056% |

Here, both the stress oscillations and energy drift in standard MPM are considerably higher. This is an **observed benchmark-specific** result, not a general proof that CPDI or cpGIMP outperforms other interpolation methods.

All four methods have nonzero axial internal force, nonzero axial acceleration, positive incremental Jacobians, unchanged particle mass, and axial momentum conservation to floating-point accuracy. In the baseline, 112 particle-center cell-crossing events were counted by the diagnostic (counted across particles and time steps).

For CPDI1, grid refinement (2 PPC, Δt=0.003 s) gives:

| Grid spacing h | Final relative σxx L2 error |
|---:|---:|
| 0.500 m | 5.498% |
| 0.250 m | 1.504% |
| 0.125 m | 0.495% |

The CPDI stress error decreases with grid refinement. In contrast, **standard MPM error is not monotonic** (17.590%, 26.462%, 20.313%) in the same experiment, and the finest MPM mesh shows a larger kinetic+strain-energy drift (about 6.29%). This is a limitation/observation to investigate, not a passing convergence test for MPM.

The continuum energy expression used for diagnostic checking is

\[
E(t)=\int_{\Omega_0}\left[\frac12\rho_0 v^2+M(J\ln J-J+1)\right]dV_0.
\]

This energy potential is valid for the chosen *axial* reduction (because first Piola stress equals σxx along x); it is **not** an asserted stored-energy function for general two-dimensional Jaumann hypoelasticity. The reported discrete energy drift uses particle quadrature of this 1D expression and is a useful diagnostic, not an exact discrete invariant.

## 4. Reproduction

From the project root, with `.venv` activated and editable installation present:

```bash
python -m validation.stage10e.nonlinear_wave --refinement
python -m pytest -q tests/test_stage10e_nonlinear_wave.py
```

Optional sensitivity:

```bash
python -m validation.stage10e.nonlinear_wave --ppc-x 4 --dt 0.0015 --output validation/results/stage10e_ppc4
```

Files produced in `validation/results/stage10e/`: `10E_summary.json`, `10E_cases.csv`, `10E_history.csv`, `10E_stress_profile.png`, `10E_error_history.png`, and `10E_refinement.png`.

## 5. Tests and interpretation

The Stage 10E tests independently check the characteristic inversion, finite-amplitude initial state, compatibility of initial physical volume and MPM-relative deformation gradient, exact PDE residual via centered finite differences, stress/stretch relation, positive deformation, force feedback, mass and momentum, an axial energy diagnostic, and CPDI spatial refinement.

The numerical stage is **complete for the axial finite-stretch benchmark**, not for force-driven general 2D large shear and rotation. The latter remain a research/validation gap before claiming full large-deformation CPDI reliability for runout or advancing directly to advanced plasticity.
